# HA Codex Chat (Test)

Personal test version of the Home Assistant add-on, based on [Bert4444/ha-codex-fixed](https://github.com/Bert4444/ha-codex-fixed). Adds a spellchecked, multiline text composer to the existing ttyd interface.

Development build v1.2.7.5. Offline checks completed, but this has **not** been build-tested or verified inside Home Assistant yet.

Add this GitHub repository URL to Home Assistant: Settings → Apps → Install app → ⋮ → Repositories. Install **HA Codex Chat (Test)** separately.

Do not remove the original HA Codex Fixed add-on. The test add-on has a separate app identity and persistent data; you may need to sign in again.

Do not upload actual `/config/codex` contents, session information, keys or Home Assistant configuration to this public repository.
